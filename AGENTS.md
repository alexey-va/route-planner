# AGENTS.md — route-planner

React/Vite-приложение для расчёта стоимости доставки и построения маршрута
через Яндекс Карты. Рабочая директория: `route-planner/`.

## Карта кода

```text
src/
├── App.jsx                    # состояние формы и композиция экрана
├── Test.jsx                   # Яндекс Карты, маршрут и зоны доставки
├── script.jsx                 # расчёт тарифа и конфигурация машин
├── components/                # история, подсказки и справочник тарифов
├── hooks/                     # localStorage, история и доступ к подсказкам
└── utils/                     # чистые расчёты, форматирование и валидация
```

`data.geojson` содержит зоны доставки и копируется в production bundle
Dockerfile-ом.

## Правила изменений

- Тарифные значения хранятся в `src/script.jsx`; отображение справки строится
  из тех же `config` и `vehiclesConfig`.
- Чистую бизнес-логику размещай в `src/utils/` и покрывай Vitest-тестами.
- Состояние, которое должно переживать перезагрузку, веди через
  `useLocalStorage`.
- Изменения карты держи в `Test.jsx`; не смешивай их с расчётом цены.
- Не коммить ключи, пароли и новые production credentials. Ключ браузерного
  API Яндекс Карт всё равно ограничивай разрешёнными доменами.
- Сохраняй публичный URL и формат `data.geojson`, если задача явно не требует
  миграции.

## Проверка

Минимум перед завершением:

```bash
npm test -- --run
npm run build
git diff --check
```

Для изменений тарифа добавь или обнови отдельный тест в `src/script.test.jsx`
или `src/utils/*test*`.

## Деплой

`.woodpecker.yml` запускается для push/manual на ветке `master`. Push может
изменить production и не используется как локальная проверка.
